Exolobe ドキュメント

Google Meet / Zoom などの Web 会議を Mac で録音し、文字起こし・話者識別・要約までを この Mac の中だけで完結させるデスクトップアプリです。音声もテキストも外部には送信しません。

  • 仕様 できること、動作要件、保存されるファイル、画面構成
  • アーキテクチャ 層構造、依存の向き、処理パイプライン、プロセス構成
  • 意思決定記録 何を採用し、何を不採用にしたか。その根拠と実測値

このアプリを支えている 3 つの判断

1. 仮想オーディオデバイスを使わずにデスクトップ音声を録る

BlackHole のような仮想デバイスの導入も、画面収録の許可も求めません。macOS 14.2 以降の Core Audio Process Tap でシステム出力を複製して取得します。権限は 「オーディオ録音のみ」で済み、画面収録の紫インジケータは点灯しません。 → ADR-001

2. 相手と自分を最初から別トラックで録る

システム音声（＝相手）とマイク（＝自分）を別々の WAV に同時録音します。これにより 2 話者の分離が推論なしで確定し、文字起こしもクロストークの影響を受けません。 相手側をさらに複数人へ分けるクラスタリングは、この土台の上に任意機能として乗せています。 → ADR-006

3. すべてローカルで完結させ、外部デーモンにも依存しない

文字起こしは whisper.cpp、要約は node-llama-cpp で動かします。Ollama のような常駐サーバーは 不要で、モデルはアプリが自分でダウンロードして管理します。配布版の利用者に Homebrew も 手動ダウンロードも求めません。 → ADR-003

実測に基づく注意点。 音声コーデックの既定は AAC-LC です。HE-AAC（aach）を 16kHz モノラルに指定すると afconvert は指定ビットレートを無視してコアを 8kHz・約 10kbps まで落とします。 容量は小さくなりますが会議音声の明瞭さを損なうため採用していません。 → ADR-005
